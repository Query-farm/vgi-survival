## Run locally or in Colab

Open either Colab link and run all. Locally, from this directory:

```sh

uv run --locked vgi-notebooks --timeout 300
```

Choose `.venv/bin/python` as an interactive kernel. Standalone setup installs the
shared base package while preserving compatible preloaded kernel/plot libraries.
The local environment additionally includes the execution runner. Presentation
helpers and authored fixtures download from an immutable public revision and are

## Inputs and interpretation

The first notebook preserves the original [24-device fixture](fixtures/followup.csv)
and its [provenance](fixtures/provenance.json). Every record is invented. Event
coding is 1 for observed failure and 0 for right-censoring. The observation cutoff
changes the recorded relation, not a latent failure process. Twelve SQL checks
reconcile counts, risk sets, product-limit estimates, confidence bounds and the
first half-survival crossing. An infinite median means unreached during observed
follow-up, not infinite device lifetime.

The second uses [80 simulated devices](fixtures/load_followup.csv) generated by
[generate_load_fixture.py](generate_load_fixture.py), with seed and algorithm in
[load_provenance.json](fixtures/load_provenance.json). Load affects the generating
exponential rate; observation stops are drawn independently. No fitted answers
are stored in the generator. SQL discovers methods, compares fixed load groups
with log-rank, and fits only a continuous numeric load covariate with Cox.

A hazard ratio requires its covariate increment. The notebook rescales the fitted
ratio and its 95% interval to a common ten-point contrast and checks them against
a second fixed-unit worker fit. Thirteen SQL checks include coefficient scaling,
ratio/interval equality and unchanged Wald p-values. Group comparison and Cox
answer different questions; neither diagnoses proportional hazards or supports
a causal claim about real devices. Confidence bounds are pointwise estimator
output for synthetic inputs, not calibrated evidence for an external population.

## Run the experiments separately

```sh
uv run --locked vgi-notebooks 01_censoring_risk_sets_and_median.ipynb \
 --parameters '{"FOLLOWUP_DAYS":8}' --output-dir artifacts/shorter-followup

uv run --locked vgi-notebooks 02_hazard_ratios_need_a_unit.ipynb \
 --parameters '{"LOAD_STEP":5}' --output-dir artifacts/five-point-load
```

The first retains identical events and starting risk sets through day8 while
censoring later observations at day8. Its median becomes unreached. Allowed
integer cutoffs are1–22; restore16 for the saved default.

The second halves the fitted coefficient and takes square roots of the reported
ratio/interval endpoints. The ten-point contrast, p-value, group curves and
log-rank result remain fixed. Allowed integer increments are5 and10; restore10.

The shared runner requires separate outputs for overrides and only writes after
success. Default/experiment runs, changed figures, parameter guards and one
fresh preloaded-kernel bootstrap are checked. Hosted Colab is not manually
operated. Review PNGs and experiment copies are ignored; published SVGs remain.
